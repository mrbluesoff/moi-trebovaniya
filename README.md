## User Story: Просмотр списка заказов

**Как** менеджер склада
**Я хочу** видеть список всех заказов
**Чтобы** контролировать статус выполнения

### Критерии приемки
- [ ] Список отображает заказы за последние 30 дней
- [ ] Каждый заказ показывает статус (новый/в работе/выполнен)
- [ ] Есть фильтр по статусу

| Поле | Тип | Обязательное |
|---|---|---|
| id | number | да |
| status | string | да |

## User Story: Экспорт заказов в Excel

**Как** руководитель отдела продаж
**Я хочу** выгружать список заказов в Excel
**Чтобы** делать отчётность для руководства

### Критерии приемки
- [ ] Кнопка "Экспорт" доступна на странице заказов
- [ ] Файл включает все видимые на странице колонки
